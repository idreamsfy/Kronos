## 💾 内存配置详解

### 为什么内存如此重要？

Apple Silicon 使用**统一内存架构** (UMA)：

```
┌──────────────────────────────────┐
│      统一内存池 (Unified Memory)      │
│                                  │
│  ┌────────────┐  ┌────────────┐  │
│  │    CPU     │  │    GPU     │  │
│  │  (通用计算) │  │  (MPS加速) │  │
│  └────────────┘  └────────────┘  │
│                                  │
│  两者共享同一内存，无需数据复制     │
└──────────────────────────────────┘
```

### 内存分配示例 (M1 16GB)

```
总内存: 16GB
├─ 系统占用: 2-3 GB
├─ 应用程序: 2-3 GB
├─ Kronos 模型: 2-4 GB
├─ 训练数据: 1-2 GB
├─ 中间激活: 2-4 GB
└─ 可用余量: 2-4 GB
```

### 不同内存配置的能力

| 内存 | 推理能力 | 训练能力 | 推荐场景 |
|------|---------|---------|---------|
| **8GB** | mini/small | ❌ 几乎无法训练 | ❌ 不推荐 |
| **16GB** | 所有模型 | small/base (小batch) | ✅ 入门学习 |
| **32GB** | 所有模型 | base (中等batch) | ✅✅ 推荐 |
| **64GB** | 所有模型 | base/large (大批次) | ✅✅✅ 专业 |
| **128GB+** | 所有模型 | 大规模并行训练 | ✅✅✅✅ 顶级 |

## 🔧 优化技巧

### 1. 根据内存调整 Batch Size

```python
# 8GB 内存 (不推荐)
batch_size = 4
num_workers = 0

# 16GB 内存 (您的配置)
batch_size = 8-16
num_workers = 0

# 32GB 内存
batch_size = 32-50
num_workers = 2

# 64GB+ 内存
batch_size = 64-100
num_workers = 4
```

### 2. macOS 专属优化

```python
import torch

# 确保使用 MPS
device = torch.device('mps' if torch.backends.mps.is_available() else 'cpu')
print(f"Using device: {device}")

# DataLoader 配置 (macOS 关键)
from torch.utils.data import DataLoader

train_loader = DataLoader(
    dataset,
    batch_size=16,
    num_workers=0,  # ⚠️ macOS 必须设为 0
    pin_memory=False,  # ⚠️ macOS 不支持
    persistent_workers=False
)
```

### 3. 内存管理

```python
import gc
import torch

# 每个 epoch 后清理
def cleanup():
    gc.collect()
    if torch.backends.mps.is_available():
        torch.mps.empty_cache()

# 使用示例
for epoch in range(epochs):
    train_one_epoch()
    cleanup()  # 释放内存
```

### 4. 减少内存占用

```python
# 方法 1: 梯度检查点
model.gradient_checkpointing_enable()
# 节省 40-60% 内存，速度降低 20-30%

# 方法 2: 混合精度
scaler = torch.cuda.amp.GradScaler()
with torch.cuda.amp.autocast():
    output = model(input)
    loss = criterion(output, target)

# 方法 3: 减小序列长度
lookback = 200  # 从 512 降到 200
```

### 5. 监控系统资源

```bash
# 实时监控
top -o cpu  # CPU 使用
top -o mem  # 内存使用

# 查看 MPS 状态
sudo powermetrics --samplers gpu_power -i 1000
```

## ⚠️ 常见问题

### Q1: 我的 M1 16GB 够用吗？

**A**: ✅ 够用！
- 推理: 完全没问题
- 训练: 可以训练 Kronos-base (batch_size 8-16)
- 建议: 关闭其他应用，专注训练

**您当前的配置完全可以胜任学习和中小规模训练！**

---

### Q2: 8GB Mac 能跑吗？

**A**: ⚠️ 勉强可以，但不推荐
- 推理: Kronos-mini/small 可以
- 训练: 非常困难，经常内存不足
- 建议: 至少升级到 16GB

---

### Q3: M1 vs M2 vs M3，差距大吗？

**A**: 
```
M1 → M2: 提升 ~15-20%
M2 → M3: 提升 ~15-20%
M1 → M3: 提升 ~30-40%
```

对于 Kronos 训练：
- M1 16GB: ~180秒/epoch
- M2 16GB: ~150秒/epoch
- M3 16GB: ~130秒/epoch

**结论**: 有提升，但不是质的飞跃。**内存大小更重要！**

---

### Q4: MacBook Air vs MacBook Pro？

**A**:

| 对比项 | Air | Pro |
|-------|-----|-----|
| **性能** | 短时爆发强 | 持续稳定 |

**建议**: 
- 偶尔训练 → Air 足够
- 频繁训练 → Pro 更稳定
