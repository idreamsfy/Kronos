## 💡 选购建议

### 关键考虑因素

#### 1. 显存容量 (最重要)

```
Kronos-mini:   最少 4GB, 推荐 8GB
Kronos-small:  最少 6GB, 推荐 12GB
Kronos-base:   最少 8GB, 推荐 16GB
Kronos-large:  最少 16GB, 推荐 24GB+
```

**原则**: 显存越大越好，可以支持更大的 batch size

#### 2. 计算能力

- **CUDA Cores / Tensor Cores**: 越多越快
- **内存带宽**: 影响数据加载速度
- **架构代次**: Ampere (30系) < Ada (40系) < Hopper (H100)

#### 3. 功耗和散热

- **桌面 GPU**: 需要足够电源和散热
- **笔记本 GPU**: 注意功耗限制
- **Apple Silicon**: 能效比最优

#### 4. 预算分配

```
总预算 ¥3,000:  RTX 3060 12GB (最佳性价比)
总预算 ¥6,000:  RTX 4070 Ti Super 16GB
总预算 ¥10,000: RTX 3090 24GB 二手 或 RTX 4070 Ti Super
总预算 ¥15,000: RTX 4090 24GB (最佳选择)
总预算 ¥30,000+: RTX A6000 或双 RTX 4090
```

## 🔧 优化技巧

### 1. 根据显存调整 Batch Size

```python
# RTX 3060 (12GB)
batch_size = 16

# RTX 4070 Ti (16GB)
batch_size = 32

# RTX 3090/4090 (24GB)
batch_size = 64

# A100 (40GB)
batch_size = 128
```

### 2. 使用梯度累积

如果显存不足，可以使用梯度累积模拟大 batch size：

```python
# 物理 batch_size = 8, 累积 4 次 = 等效 batch_size = 32
accumulation_steps = 4
```

### 3. 混合精度训练

使用 FP16/BF16 减少显存占用：

```python
# PyTorch AMP
scaler = torch.cuda.amp.GradScaler()
with torch.cuda.amp.autocast():
    output = model(input)
    loss = criterion(output, target)
```

### 4. 数据预加载

使用 DataLoader 的 num_workers 加速数据加载：

```python
DataLoader(dataset, batch_size=32, num_workers=4, pin_memory=True)
```

## ⚠️ 注意事项

### 购买前检查

4. **主板兼容性**: PCIe x16 插槽

1. **NVIDIA GPU**:

   - 安装 CUDA Toolkit 11.8+
