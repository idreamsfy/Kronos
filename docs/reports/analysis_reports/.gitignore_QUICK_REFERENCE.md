# .gitignore 快速参考

## 🚫 被忽略的文件类型

### 数据文件
- `*.csv` - 所有CSV数据文件（~8.5 MB）
- `*.feather`, `*.parquet`, `*.h5` - 其他数据格式

### 模型文件
- `*.safetensors` - 模型权重（~800 MB）
- `*.pth`, `*.pt`, `*.ckpt`, `*.bin` - PyTorch模型

### 训练输出
- `outputs/finetuned_models/*/basemodel/` - 预测器模型
- `outputs/finetuned_models/*/tokenizer/` - 分词器模型
- `finetune_csv/logs/` - 训练日志

### 预测结果
- `prediction_results/` - 预测JSON文件
- `figures/*_prediction_*.png` - 预测图表

---

## ✅ 保留的文件类型

### 代码和脚本
- `*.py` - Python源代码
- `tests/*.py` - 测试脚本

### 配置文件
- `*.yaml` - 训练配置
- `*.json` - 模型配置（不含权重）

### 文档
- `*.md` - Markdown文档
- `data/README.md` - 数据说明
- `outputs/**/README.md` - 模型说明

### 图表
- `figures/*.png` - 非预测相关的图表

---

## 🔍 常用命令

### 检查文件是否被忽略
```bash
git check-ignore -v filename
```

### 查看当前状态
```bash
git status --short
```

### 强制添加被忽略的文件（不推荐）
```bash
git add -f filename
```

### 清除缓存并重新应用规则
```bash
git rm -r --cached .
git add .
git commit -m "Refresh Git cache"
```
